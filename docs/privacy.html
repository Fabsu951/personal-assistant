Privacy policy

Last updated: 20 October 2026

Ragnar is a personal assistant used by one person, its owner. It is not offered to the public, and only the owner's Telegram account can talk to it.

What data it accesses

  • Gmail: reads and searches the owner's email, creates drafts, and sends or archives email only after the owner approves each action.
  • Google Calendar: reads the owner's calendars and creates or deletes events only after the owner approves each action.
  • Google Drive: searches and reads the owner's files (read-only).
  • Messages, voice messages, tasks, notes, expenses and training data the owner sends to the assistant.

How it is used and where it goes

  • Data is used only to answer the owner's own requests.
  • To produce answers, the relevant text is sent to Anthropic's Claude API. Voice messages are sent to OpenAI's speech-to-text API to be turned into text.
  • The Google login token, chat history, tasks, notes and other data are stored in a private database on the owner's own server (Railway).
  • Data is never sold, shared with anyone else, or used for advertising.

Google user data

Ragnar's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

Google access can be revoked at any time at myaccount.google.com/permissions. Deleting the assistant's database removes all stored data.
